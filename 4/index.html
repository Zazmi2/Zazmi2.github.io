Part 0 — Camera Calibration & Dataset Capture

0.1 Calibration Results

For camera calibration, I captured 30–50 images of the provided 4×4 ArUco tags using my phone, keeping the focal length fixed. I varied the viewing angle and distance to ensure a well-conditioned calibration set. For each image, I used OpenCV’s ArUco detector to locate markers:

  • Detected ArUco corners using cv2.aruco.ArucoDetector
  • For each detected tag, extracted its 2D image corner coordinates
  • Assigned corresponding 3D corners assuming a known physical tag size (e.g., a 2 cm × 2 cm tag with corners [(0,0,0), (0.02,0,0), (0.02,0.02,0), (0,0.02,0)])
  • Accumulated valid 2D ↔ 3D correspondences across all images (skipping images where no tag was detected)
  • Used cv2.calibrateCamera() to solve for intrinsic matrix K, distortion coefficients, and per-image poses
This process produced the final camera intrinsics and distortion parameters used for the rest of the project, along with debug visualizations confirming correct ArUco detection.

Part 1 — Neural Field for 2D Image

Part 1 — Neural Field for 2D Image

Implementation Summary

In this part, I experimented with representing 2D images using a Neural Field (essentially a 2D version of a NeRF). I built a Multilayer Perceptron (MLP) with Sinusoidal Positional Encoding (PE) to map pixel coordinates to RGB values. The MLP uses fully connected layers with ReLU activations, and a final Sigmoid to constrain pixel colors to the [0, 1] range. Inputs were normalized coordinates (x/image_width, y/image_height) and colors were normalized to [0,1] as well.

Hyperparameter Experiments

I experimented with different positional encoding frequency levels (L = 2, 6) and network widths (channel sizes = 64, 256). Sampling 10k pixels per iteration allowed training without GPU memory issues. Training ran for 10000 iterations using Adam with learning rate 1e-3. I backproped using MSE loss, and PSNR was computed to evaluate reconstruction quality.

Results: Effect of Positional Encoding and Network Width

Higher positional encoding frequencies allow the network to capture finer details in the image, while wider networks (more channels per layer) provide higher representational capacity. Combining higher PE and wider layers produces the most accurate reconstructions.

Part 2 — Full NeRF

Background: Replicating the Lego NeRF from the Original Paper

As part of this project, I replicated the Neural Radiance Field (NeRF) results on the Lego scene, a canonical dataset from the original NeRF paper. Using the provided multi-view images and camera parameters from the authors, I trained the model to synthesize novel views that closely match those shown in the paper.

Implementation Summary, Part 2.1: Transformations

  • First, I implemented the transformation from camera coordinates to world coordinates using rotation and translation matrices.
  • Next, I converted 3D points in the camera coordinate system to 2D pixel coordinates using the camera intrinsic matrix.
  • Then, I implemented the inverse process to convert pixel coordinates back to camera coordinates, given a depth value.
  • After that, I generated rays for each pixel by defining ray origins and normalized directions in world space.
  • I made sure these ray generation functions support batched inputs for efficiency.

Implementation Summary, Part 2.2: Sampling

  • Following ray creation, I sampled rays from multiple images by either sampling a fixed number of rays per image or globally across all pixels.
  • Then, I discretized each ray by sampling points uniformly between near and far planes along the ray.
  • To improve training robustness, I added small random perturbations to the sample points during training, preventing overfitting.
  • I used 32 or 64 samples per ray as recommended for the project.

Dataloader Integration

To bring all components together, I created a RaysData dataloader class, which integrates images, camera intrinsics, and camera-to-world transformations to provide batched rays and corresponding pixel colors for training. This class:

  • Accepts multiple images along with their camera intrinsics (K) and extrinsics (c2ws).
  • Precomputes rays’ origins and directions for every pixel in all images using the pixel_to_ray function.
  • Stores the rays and pixel RGB values for efficient sampling.
  • Supports sampling random rays across all images to form batches during training.
  • Includes utility methods to retrieve rays from specific images or sample random rays globally.

This dataloader effectively unifies coordinate transformations, ray generation, and pixel supervision, enabling streamlined training of the NeRF model.

Implementation Details: Neural Radiance Field (NeRF) Architecture and Volume Rendering

MLP Architecture

The neural network backbone is a multi-layer perceptron designed to predict color and density for 3D points and viewing directions. To capture fine details, inputs are first transformed with positional encoding, which maps coordinates into a high-frequency space allowing the network to model complex variations.

  • Input Encoding: Positional encoding is applied to map 3D input coordinates and viewing directions into a higher-dimensional space with multiple frequency bands. This enables the network to capture high-frequency variations more effectively.
  • Network Structure: The MLP consists of two main blocks:
    • The first block processes the encoded 3D position through several fully connected layers with ReLU activations.
    • The intermediate output is concatenated with the encoded input and passed through a second block of layers to increase representational power.
  • Output: The network predicts two quantities:
    • Density (sigma): Constrained to be non-negative using ReLU.
    • RGB color: Dependent on both learned features and the encoded view direction, with values constrained between 0 and 1 via Sigmoid activation.

Volume Rendering

The volume rendering step integrates predicted densities and colors along camera rays to produce the final pixel color. The process involves:

  • Calculating alpha values representing the probability of light absorption at each sample point.
  • Computing transmittance, the probability that light travels through samples without absorption.
  • Determining weights by combining alpha and transmittance, which quantify each sample’s contribution.
  • Summing weighted colors to obtain the final rendered pixel color.

This discrete volume rendering approximation effectively models how light accumulates and attenuates through the scene, enabling realistic, view-dependent synthesis.
